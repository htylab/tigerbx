# Contributors

TigerBx began on 2021-08-23 as **tigerseg** (first public release 0.09 on 2021-08-28) and is led by
[@htylab](https://github.com/htylab). The people below contributed code, models and documentation from 2021 to 2025.

| Contributor | GitHub | Years | Contributions |
|-------------|--------|-------|---------------|
| JENNSHIUAN | [@JENNSHIUAN](https://github.com/JENNSHIUAN) | 2021 | First public release (tigerseg 0.09): 3D U-Net subcortical segmentation, package layout and README |
| kuogeo123 | [@kuogeo123](https://github.com/kuogeo123) | 2021-2022 | Releases 0.1.0-0.1.6: TensorFlow 2, then ONNX Runtime inference and the model hub; segmentation modes, `-i` / `-o` options, the aseg2 and VDM tools, resolution-tagged models, build scripts, the tigerbet brain-extraction tool |
| erichacha | [@erichacha](https://github.com/erichacha) | 2023 | Cortical-thickness model, README updates |
